# 🎮 Steam Reviews NLP Dashboard

NLP project analyzing 50,000 Steam reviews with sentiment analysis and topic modeling.

---

## 📊 Features
- Sentiment analysis (positive / negative)
- Topic modeling (BERTopic)
- Interactive Streamlit dashboard
- MLflow tracking

---

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-learn
- BERTopic
- Streamlit
- Plotly
- MLflow

---

## 🚀 Run project

```bash
pip install -r requirements.txt
streamlit run dashboard.py
